# AGENTS

This repository is being built incrementally with agent assistance.

## Working Norms

- Keep changes small and easy to review.
- Prefer clear interfaces before implementation detail.
- Update docs and specs alongside behavior changes.
- Preserve a simple local developer experience.

## Repo Expectations

- Put product and technical design notes in `spec/`.
- Keep the root README focused on project positioning and quick start.
- Add implementation code only after the corresponding spec is clear enough to guide it.

## Change Checklist

- State the intent of the change.
- Capture any new assumptions in docs or specs.
- Leave the repository in a clean git state when possible.
